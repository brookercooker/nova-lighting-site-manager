# Site Manager (src/pages/admin) rules
- Library List/Grid uses shared LibraryListRow actions and libraryView scoped preferences; parent selection/filter/paging state stays layout-independent, and LibraryWindow retains grid geometry while releasing distant media.
- Media/object grids use their library content container: one column below 340px, then two/three/four/five from 340/540/720/900px (maximum five); thresholds reserve the existing 12px gap and phone margins for at least 160px cards, without changing List or Pages grids.
- Library Edit mode uses the same SelectionBar callbacks in a phone bottom bar with zero-selection actions disabled; Users uses responsive table-as-cards styling to keep a single action/role data path.
- Library card labels share LibraryCardLabels and libraryLabels for bounded names, overflow and additive filters; card menus use LabelsCell for item assignment, while global management lives only in the header/Filters so actions cannot be confused.
- Filters, item label editors and chat label menus share memoized LabelSearchList and objectLabelFilter normalization, with local search, bounded native scrolling and capture-phase Escape clearing before overlay dismissal; no new persistent state. Item usage counts read existing scoped label arrays through useLabelUsageCounts.
- Used On uses always-visible UsedOnChoices search with no page results until nonblank typing, bounded matching results and removable single-selection chips (preserving existing filter cardinality); only real selection sets aria-pressed and neutral focus/hover must not imply selection. Management presents a flat full-width label list while retaining hierarchical edit/delete operations, so phone names and actions remain readable without changing storage.
- Audit titles use a capped first-line presentation with expandable full saved wording, never changing link identity/search; count copy distinguishes current versus removed/filter results and shared-chrome deduplication from raw inventory totals.
- Capture shares captureName sanitation at field blur and upload boundaries; database triggers sanitize stored media names independently. Confirm Clear for multiple items and guard router/browser departures while unuploaded Files remain, because staging is memory-only.
- Libraries (including both Pages views) share LibraryFilterToolbar staged state/live predicates and LibraryListRow, while global label management stays in the header and Filters footer; filter choices never open nested layers. Saved inert page thumbnails avoid mounting visitor dependencies in list rows. label colour/edit/delete controls reserve spaced 44px areas with named, direct-usage deletion confirmation. Optional landing dates require end > start, while expired schedules warn without blocking; phone page tabs reserve 44px height.
- Link Audit uses container-sized cards below the table's usable width, never viewport-only switches; shared pagination/filter state serves both layouts. Link Removed describes historical row removal (not target-page deletion), while Link Works/Page Not Found/Couldn't Check (Timed Out) describe scan results. Timed-out scans retry twice with 2x/3x timeouts before reporting, never retry actual Coming Soon/not-found replies.
- Text origin metadata is transport-only outside the verbatim core: retain first reported coded wording with its edit, remove orphan metadata, and handle trusted stale/restore messages through existing history/save paths.
- Libraries release distant media-card contents with reserved geometry; mini previews are inert with observed tab-stop removal. Pages refetch on focus/mutations and discard superseded reads, so stale responses cannot resurrect deleted rows.
- Use only bun.lock; keep compatible patched dependency overrides and handle Zod's major migration separately. Storage transforms are unavailable here, so thumbnail signing uses existing web assets without render requests.
- Phone toolbar keeps Manual libraries and the mode switch in the overflow (shared useModeSwitchActions, chooser rendered outside the menu); non-stretching tabs, a flex-1 labelled Capture and 44px controls keep both modes within the viewport.
- Phone header centers Capture independently of its side controls; Preview/Menu are icon-only and one content dropdown reuses externally anchored LibraryPicker or existing requestAdd/navigation handlers. Non-phone controls and review hiding remain unchanged.
- Yellow/black is only for objects/images/videos chosen for the next chat message in pickers and the selected-items strip above chat. Library management/Select cards never use yellow; retain neutral surfaces, black outlines and checkboxes. Labels/filters keep their own colours, and sort/range keep black selection.
- Undo-pending draft gates disable every Submit control and display the relay reason; request undo flags only label cards, never grant authority.
- Developer Review shares the header draft URL with its token message; warm auth before mounting, answer trusted child requests/load from memory, and bound the trusted-ready loading cover to 20 seconds to avoid handshake stalls.
- Failed waits share persisted deadlines and interaction ownership; retry only captured prepared /send payloads, with a synchronous duplicate-send gate and history recovery, never reconstruct missing attachments or page context.
- Chat connection retry and browser online events use the shared poller's immediate refresh, not send retries; automatic refreshSoon retains back-off, while 401/403 show the existing sign-in note rather than an outage.

- More Labels command lists stop wheel/touch propagation and contain overscroll in a viewport-bounded scroller, preserving native input without reaching the enclosing Dialog's document scroll lock or the page behind it.
- Chat navigation exposes a separate optimistic destination for toolbar feedback and a 150ms cue; only validated matching locations update page data/history, superseded replies are ignored, and retained-frame navigation keeps its single fallback. After a Manager destination matches, ignore conflicting reports from that preview window for a non-extending 1.5s settling window; new requests, replacement/editor windows and expiry release the guard, since cross-origin SPA location/intent cannot be read from iframe.src.

- Top-bar Objects/Images/Videos use LibraryPicker on Preview in Chat Mode, EditorSlot.requestAdd in page Manual Edit Mode (append beneath original, no add row), and navigate on management tabs. All pickers share TopDropContent: measured opener/toolbar/area bounds, right-edge flip/clamp, resize observation, connector, pressed opener and focus return keep panels attached without layout shift. LibraryPicker deduplicates attached refs, shows eight top label chips plus selected non-top object labels and a counted searchable folder menu, and sends DesignChatContext refs as plain text appended to the message; /send never changes.
- Objects open in the same DesignTab/FramedPageEditor at `/__object/<id>?nova-edit=1` (`?editObject=` on /manage/preview; /manage/objects/design redirects unless `legacy=1`); edit-init/update send `scope:"object"` + `object` snapshot (+ `edits` override), frames must announce `capabilities.objectEditing`, every object edits under `object:<id>`, `edit-error` shows Retry. Designed objects = not a registered coded component (component_key may remain); their sections are the held blocks (no page marker) saved to object_registry.content, with per-section Section Layout. The standalone designer stays only for objectSectionsEdit LAYOUT_GAPS and new-object creation.
- Every object click (shared, site-wide, used only here, or a page-only copy) goes through ObjectClickDialog in two steps: first "Shared Object/Object/Site Header" saying it is edited separately with Open in Object Editor / Cancel, then a warning naming where changes appear (other pages, whole site, or only this page) with Open (Edit Everywhere) / Make a Copy (shared only) / Back / Cancel. objectClickAction remains exported but DesignTab no longer opens objects straight away.
- Editor saves go through saveRow, which treats an update that returns no row as a failure (RLS skips are silent); paths starting with `/__`, /manage, /admin or /preview are never registered as pages (isInternalPath).
- Object status is a deprecated compatibility field, never an availability gate; creation defaults and frame snapshots remain compatible with older consumers while archive checks determine availability.
- sectionList-capable frames supply bounded, trusted edit-sections snapshots; row selection sends scroll-to-section, held mutations use Manager state and coded section commands must return edit-change for persistence. Older frames retain the local list; snapshots never enter stored content.
- Reset actions are staged until Save Changes, page reset never clears shared-object overrides, and object reset only clears its object:<id> map.
- rangeFormatting-capable frames report validated edit-range for the current selected key/scope; inert selections carry marks and guarded edit-format senders. Formatting remains frame-owned and resulting edit-change enters the existing Manager save/history pipeline, avoiding cross-frame DOM ranges or a second persistence path. Selection descriptions accept legacy string and structured section/role context and prefer frame plain text over flattened HTML; range updates never deselect. Computed colours/font stacks are display metadata, not restricted to palette/menu values.
- SelectedWording patches sanitized text nodes with fast-diff and writes the existing HTML inline key; unchanged formatting survives and normal edit-update/save/history remain authoritative, without a separate text storage path.
- Page picture removal emits hidden:<path>="1"; form hints emit placeholder:<path> strings sliced to 300 characters, clearing removes the override. Public 89e55b8's verbatim core validates both kinds, so incoming mixed maps remain intact; validation is not proof of DOM replay. Material icons use the trusted iconMarkup adapter, never pasted HTML.
- Collapsed rail expansion is tied to dropdown onOpenChange (not click alone, since Radix opens on pointerdown); Review expands before toggling so actions are visible.
- Link-address choices are non-submitting buttons that preserve mouse focus and only write link overrides, never Manager navigation; field pointerdown/focus/click each open the chooser. Material help uses explicit hover/focus state in a portalled tooltip above editing layers so pointer-origin focus cannot suppress keyboard help.
- Resolve colour tokens to concrete hex before edit-format; public frames do not inherit Manager CSS variables. Position stores px letter spacing and unitless line height. Frame object placements are trusted session metadata merged with manifest/saved usage, never page content. Held section rows update optimistically from Manager history, and equal frame payloads are not resent to avoid redundant public replays.
- Preview snapshots refresh on every trusted preview-ready, iframe load and mode/page transition, logging counts and reason only; this keeps a retained Chat iframe current without reloads or listener recreation.
- Chat and Manual frames share the public-preview base; only retain embed credentials when its origin matches the configured public site, never render Manager-local pages in Chat, and compose page paths by replacement rather than appending to an embed route.
- Library image references use stored delivery URLs in web/fallback/original order, never storage URLs synthesized from web_path; thumbnail fallbacks share the same candidates while signed/local previews retain priority.
- Manager owns document.title while mounted so visitor thumbnail effects cannot change it; page tables use container-aware secondary-column hiding and fixed right actions to preserve names/status/actions in the available pane.
- Trusted edit-key Delete/Backspace invokes the same reversible hidden edit as Delete Image only for the current image selection; footer selections use the site-wide object confirmation.
- Narrow screens use useManagerLayout tiers: phone Chat is a retained pop-out sheet with presentation-only attention signals; Manual keeps its Page/Sections tabs and edit sheet. Tablet/laptop keep the remembered resizable panel and wide is unchanged. Hide, never unmount chat/preview to retain drafts and scroll. Desktop uses ScaledViewport at 1280 px; navigation stays in the toolbar.
- Phone drawing finishes without clearing marks and notifies the retained chat sheet; sending continues through the existing prepare/send path so drawing attachments retain their original protocol.
- Phone attention baselines the first loaded relay history; only later timestamps or new approval/review transitions can alert. Chat and Manual use the selected virtual device width in ScaledViewport without remounting the editor.
- Successful public page/object lifecycle, metadata and redirect mutations use the existing contentSync queue with named notes; deferred deletion notifies after commit, keeping packages current without a second queue.
- Chat draft text and selection live in DesignChatProvider above the stable composer; updates cannot erase typing/focus, and completed sends clear only their unchanged submitted draft.
- The picked working-page descriptor is validated and restored from guarded tab sessionStorage into both the chip and initial preview path (not editing state); deliberate picks replace it and initial navigation is pinned so stale home reports cannot win after reload.
- PreviewToolbar uses reported locations and the shared page loader; Chat picks use selectPage and Manual picks use the existing unsaved guard. Reload reuses Chat retry or remounts only FramedPageEditor via a local event, preserving Manager-held edits and replaying edit-init rather than writing or changing loading protocols.
- Preview navigation confirmation, history and remembered-path pins share previewHistory normalization of home aliases, trailing slashes and equivalent queries, and strip `__lovable_*` preview credentials before comparing, storing or remembering, to avoid false fallback reloads and token reuse. Back/Forward send non-sticky in-place "to" for the Manager-history address, because reloaded preview frames have no browser history of their own. Nested Managers can navigate their exact-origin child preview; accept both bare and nova-site preview-ready shapes like the snapshot/scroll bridges. Unready frames retry on trusted readiness within the single three-second fallback, never reload immediately; guarded sessionStorage nova:debug-nav=1 enables reason diagnostics without embed URLs.
- TextIconLinkPanel reuses scoped icon/link/position overrides and Manager history/save; all placement validation now goes through the verbatim shared core, avoiding divergent extension acceptance. Material name-only UI normalizes case before the existing parser; color drafts remain local to the picker until Apply so cancellation never records history or crosses the frame.
- Collapsible text expansion uses trusted selection.expandable metadata and capability-gated edit-expand requests; refreshed edit-select confirms state without content/history writes, keeping public interaction and DOM ownership in the frame. Icon previews use selected computed/overridden text size rather than picker glyph size.
- AdminShell owns one useSaveProgress view and passes it unchanged to the chat save-status line; content jobs never render the independent relay working line, preventing save-feedback dismissal drift. Manual Edit saves have no success toast; errors retain existing reporting.
- Chat StageRibbon lives above retained interactive PreviewPanel with compact phone spacing; estimated fill stays independent of signal-owned phase wording. - Chat LibraryPicker objects use objectPickerFilter for search plus hierarchical Any/All label matching; optional multi-label LibraryFilterBar props leave image/video single-label behavior unchanged and attached references independent of filters.
